# Compound Libraries

This directory contains an example compound library for virtual screening.

## Contents

* A SMILES library (`*.smi`) containing 100 compounds, along with two known active compounds identified by virtual screening from the following studies:

  * [*Hydrogen Bonding Penalty upon Ligand Binding*](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0019923)
  * [*Discovery of a Novel Chemotype of Tyrosine Kinase Inhibitors by Fragment-Based Docking and Molecular Dynamics Simulations*](https://pubs.acs.org/amclct/article-abstract/3/10/834/1350515/Discovery-of-a-Novel-Chemotype-of-Tyrosine-Kinase?redirectedFrom=fulltext)

## Notes

* The library is provided for testing and demonstration purposes only.
* Users are encouraged to replace the example library with their own compound collections for virtual screening.
